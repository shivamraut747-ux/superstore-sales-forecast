# Dataset Documentation

### Source
This project utilizes the classic **SuperStore Sales Dataset** (Retail e-commerce transactions across the US market).

### Recommended File Placement
Place your raw or cleaned CSV file in this directory:
```
data/
└── SuperStore_Sales_Dataset.csv
```

### Data Dictionary

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `Order ID` | Text | Unique transaction identifier |
| `Order Date` | Date | Date when the purchase was made |
| `Ship Date` | Date | Date when the order was shipped |
| `Ship Mode` | Text | Fulfillment class (Standard, Second Class, First Class, Same Day) |
| `Customer ID` | Text | Unique customer identifier |
| `Segment` | Text | Market segment (Consumer, Corporate, Home Office) |
| `Country` | Text | Country of delivery (United States) |
| `City` | Text | Destination city |
| `State` | Text | Destination state |
| `Region` | Text | Geographic territory (Central, East, South, West) |
| `Category` | Text | High-level product category (Office Supplies, Furniture, Technology) |
| `Sub-Category` | Text | Granular product category (Phones, Chairs, Binders, etc.) |
| `Sales` | Decimal | Dollar sales volume of the transaction |
| `Quantity` | Integer | Number of units purchased |
| `Discount` | Decimal | Discount percentage applied (0.0 - 0.8) |
| `Profit` | Decimal | Net profit/loss generated by transaction |
| `Payment Mode` | Text | Method used for checkout (COD, Online, Cards) |

### Power Query Transformations Applied
1. **Date Parsing**: Standardized `Order Date` and `Ship Date` into DateTime objects.
2. **Delivery Duration**: Generated `AvgDelivery` column using `Ship Date - Order Date`.
3. **Data Quality**: Verified zero duplicate `Order ID` + `Product ID` records and eliminated null values in primary metric columns.
